SCS vulnerability type: Secret Injection via Pull Requests
Details: An attacker-controllable GitHub context value (branch name, PR title/body, label, commit message) is interpolated directly into a script with ${{ }}.
Impact: A crafted value executes arbitrary shell commands in the job, exposing secrets and the GITHUB_TOKEN.
Fix: Pass the value through an `env:` variable and reference it as a shell variable instead of inlining `${{ }}` into `run:`/`script:`.
