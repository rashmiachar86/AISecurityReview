Stage 1 Deep-Dive

Source Code Management

NHI Types

  • Developer API tokens (GitHub, GitLab, Bitbucket)
  • Git SSH keys
  • Code signing certificates
  • Repository webhook credentials
  • Personal Access Tokens (PATs)

Key Vulnerabilities

  • Hardcoded secrets in source code
  • Credentials in version control history
  • Insufficient branch protection
  • Compromised developer workstations
  • Exposed PATs in public repos

Attack Scenarios

Token Compromise: Attacker scans public repos for leaked tokens, gaining repo write access to inject malicious code.

Git History Mining: Even after removal, credentials in git history remain extractable using tools like TruffleHog or GitLeaks.

PR Injection: Fork + pull request triggers CI pipeline with access to secrets, enabling exfiltration via malicious code in PR.

Detection Tools: GitLeaks, TruffleHog, git-secrets, GitHub Secret Scanning, pre-commit hooks.
