Case Studies 2 & 4

Codecov (2021) & CircleCI (2023)

Codecov Bash Uploader Breach — 2021

Customers affected: hundreds over 2+ months

Vector: Attackers modified Codecov's Bash Uploader script by compromising Docker image creation credentials, embedding credential-exfiltration code.

Impact: CI/CD pipelines at hundreds of customers silently exfiltrated all environment variables — including cloud keys, tokens, and signing certificates — to attacker infrastructure.

Key Lessons

  • Verify integrity of all downloaded scripts (checksum)
  • Minimize secrets in CI/CD environment variables
  • Use short-lived credentials over long-lived tokens
  • Implement secret scanning and anomaly detection in pipelines

CircleCI Security Incident — 2023

Affected: thousands of organizations

Vector: Compromised employee endpoint led to theft of session token, bypassing 2FA. Attackers gained access to CircleCI's production systems and customer secrets storage.

Impact: Customer secrets, tokens, and keys potentially exposed. Mass credential rotation required across thousands of downstream organizations.

Key Lessons

  • Secrets management systems are high-value targets
  • Automate secrets rotation for rapid response
  • Implement customer-managed encryption keys (BYOK)
  • Monitor secrets usage for anomalous access patterns
