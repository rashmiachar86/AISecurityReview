Case Study 1

SolarWinds Supply Chain Attack (2020)

18,000+

Organizations impacted

$100M+

Estimated damages

What Happened

Build System Compromise: Attackers (APT29 / Cozy Bear) gained access to SolarWinds' Orion build system, injecting a malicious DLL — SUNBURST — into legitimate software updates.

Trusted Distribution: Malicious updates were digitally signed and distributed via official channels to 18,000+ customers, including multiple US federal agencies.

NHI Vulnerabilities Exploited

  • Compromised build system service account credentials
  • Weak code signing process — signed without integrity checks
  • Over-privileged build agent access to production pipeline
  • No build provenance or attestation mechanisms
  • Insufficient build environment isolation

Lessons Learned

  • Build systems are critical infrastructure — harden aggressively
  • Implement SLSA provenance and build attestation
  • Code signing alone is insufficient without build integrity
  • Isolate build environments from production credentials
