Stage 3 Deep-Dive

Build & CI/CD Pipeline

NHI Types

  • CI/CD service accounts (Jenkins, GitHub Actions, GitLab CI)
  • Cloud provider access keys (AWS, Azure, GCP)
  • Container registry credentials
  • Artifact signing certificates
  • Deployment keys

Critical Vulnerabilities

  • Over-privileged CI/CD service accounts
  • Long-lived credentials in pipeline configs
  • Secrets exposed in build logs
  • Third-party GitHub Actions with excessive permissions
  • Unencrypted secrets in pipeline definitions

Real-World Incidents

SolarWinds (2020) — Build system compromise injected malicious code into Orion updates; 18,000+ organizations impacted.

Codecov (2021) — Bash Uploader script modified to exfiltrate CI/CD environment variables for 2+ months.

Travis CI (2021) — Secrets exposed in build logs, accessible to unauthorized users.

CircleCI (2023) — Customer secrets and tokens compromised, requiring mass credential rotation.
