Stage 5 Deep-Dive

Deployment & Runtime

NHI Types at Runtime

  • Kubernetes service accounts
  • Cloud IAM roles and service principals
  • Database connection strings
  • API keys for external services
  • TLS certificates & secrets mgmt creds (Vault)

Key Vulnerabilities

  • Secrets mounted as environment variables
  • Over-privileged Kubernetes service accounts
  • Unrotated, long-lived credentials
  • Exposed cloud metadata services (AWS IMDS)
  • Insufficient network segmentation

Attack Scenarios

Container Escape: Attacker escapes container to access host credentials or adjacent workload secrets.

SSRF to Cloud Metadata: Server-Side Request Forgery exploits AWS IMDS v1 to steal instance IAM credentials without authentication.

Kubernetes Secret Extraction: Over-permissioned pod reads all cluster secrets, enabling full cluster compromise.

Lateral Movement: Compromised service account used to pivot across microservices, accessing databases and downstream APIs.
