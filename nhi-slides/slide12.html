CI/CD Attack Vectors

Top 5 Attack Vectors in CI/CD Pipelines

01

Secret Injection via Pull Requests

Attacker forks repo, adds malicious code to exfiltrate env vars, submits PR triggering pipeline with secret access.

Restrict PR pipeline secret access; use separate pipelines for untrusted code; review all external contributions

02

Compromised Dependencies

Malicious or hijacked package steals credentials from build environment during installation scripts.

Dependency pinning; lock files; package signature verification; isolated build environments; SBOM monitoring

03

Build Log Exposure

Secrets accidentally printed during build process; logs accessible to unauthorized users or made public.

Secret redaction in logs; restricted log access; automated secret scanning; developer training

04

Compromised CI/CD Platform

Direct compromise of the CI/CD system grants access to all stored secrets and lateral movement to production.

Harden CI/CD infra; external secrets management; least privilege; network segmentation; regular audits

05

Malicious 3rd-Party Actions

Compromised GitHub Actions or Jenkins plugins with excessive permissions exfiltrate credentials at runtime.

Vet all actions/plugins; minimal permissions; pin to specific versions; prefer official/verified actions
