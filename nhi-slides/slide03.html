What Are Non-Human Identities?

NHI Types Across the Pipeline

Developer Tokens

  • GitHub / GitLab PATs
  • API access tokens
  • SSH keys

CI/CD Credentials

  • Build service accounts
  • Pipeline secrets
  • Signing certificates

Cloud Identities

  • AWS IAM roles/keys
  • Azure Service Principals
  • GCP Service Accounts

Runtime Credentials

  • Kubernetes SvcAccts
  • DB connection strings
  • Vault / Secrets Manager

Why NHIs Are Dangerous

NHIs span the entire software lifecycle — from developer commits, through CI/CD pipelines, artifact storage, to production runtime. Each stage introduces unique credential exposure risks.

Critical Gap: NHIs are often long-lived, over-privileged, and lack governance controls applied to human identities. They are prime targets because they are harder to detect when compromised.

Scale: Enterprises typically have 10-100x more NHIs than human identities, yet NHI security posture lags significantly behind human identity management maturity.
