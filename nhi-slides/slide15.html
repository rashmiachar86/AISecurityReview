Summary

Key Takeaways & Recommendations

Immediate Actions

01

Inventory All NHIs

Audit every service account, API token, and machine credential across all pipeline stages.

02

Enforce Least Privilege

Scope all NHI credentials to minimum required permissions; eliminate standing over-privileged accounts.

03

Deploy Secret Scanning

Implement pre-commit hooks + CI/CD scanning for secrets across all repositories and pipelines.

04

Use Short-Lived Credentials

Replace long-lived static credentials with OIDC-based, ephemeral tokens wherever possible.

Strategic Initiatives

05

Adopt SLSA Framework

Implement build provenance, attestation, and verification for all software artifacts.

06

Centralize Secrets Management

Deploy HashiCorp Vault or cloud-native secrets managers; eliminate secrets in config files and env vars.

07

Monitor NHI Behavior

Implement anomaly detection on NHI usage patterns — unusual access times, volumes, or destinations.

08

Generate & Monitor SBOMs

Use Syft/CycloneDX for every release; continuously monitor dependencies for compromise signals.
